# План: бот регистрации @AI_native_reg_bot

Версия от 08.10.2026. Источники: задача владельца в чате Claude Code (08.10),
`materials/BOT-BRIEF.md`, `materials/FORMS.md`, `materials/COURSE-DECISIONS.md`.

## Решения (08.10.2026, владелец)

| Вопрос | Решение |
|---|---|
| Архитектура | отдельный сервис в этом репозитории, рядом с pppp на том же Coolify; код и практики pppp переиспользуются копированием |
| Контакты на практикум | имя → почта (обязательна) → телефон (можно пропустить) → согласие; роль — одной кнопкой после записи, необязательно |
| Метки `/start` | обе схемы: `prk*` и `lp_*` → практикум, `crs*` → курс, `prk_web`/`crs_web` → привязка заявки с сайта, `wait` → лист ожидания, остальное → меню; метка первого входа не перезаписывается |
| Оплата | ЮKassa ещё не подключена. Заявка на курс → владелец подтверждает → если ссылка на оплату задана в `facts.yaml`, бот её отправляет, иначе пишет «Александр пришлёт ссылку на оплату». Бот деньги не принимает |
| Письма на почту | не делаем; в уведомлении владельцу пометка «без Telegram» (делает сервис форм) |
| Уведомления о заявках с сайта | шлёт сервис форм сайта; бот не дублирует, только привязывает чат |
| Команды владельца | `/stats`, `/export`, `/link <url>` = `/set_link practicum <url>`, `/set_link recording <url>`, `/broadcast_practicum` (P1), `/whoami` |
| Модель | DeepSeek (`LLM_PROVIDER=deepseek`), Claude подключается переменной позже |
| Платформа практикума | Яндекс Телемост; ссылку владелец задаёт командой за день до практикума |
| Политика ПД | `PRIVACY_URL=https://alexshein.com/privacy`, страницу владелец положит сам; запуск не блокирует |
| Домен | `reg.alexshein.com`, A-запись в Timeweb напрямую на сервер Coolify |
| Заявки с сайта | принимаем с 10.10 (входит в P0) |
| Процесс | один PR со всеми SPEC P0; Implementer — Claude Code в worktree; «ок, мёрджи» на каждый PR |
