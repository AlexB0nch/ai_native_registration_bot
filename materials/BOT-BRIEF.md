## Задача

Сделать Telegram-бота `@AI_native_reg_bot` для записи на бесплатный практикум
и на платный курс Александра Шеина «ИИ и вайбкодинг для консультанта по
операционным преобразованиям». Язык — русский, тон спокойный и деловой,
не больше одного эмодзи на сообщение.

## Как человек попадает в бота

Через `start` с меткой (до 64 символов, `A–Z a–z 0–9 _ -`):

| Метка | Откуда | Что делать |
|---|---|---|
| `prk` | лендинг, «запишитесь через бота» под формой практикума | сценарий практикума |
| `crs` | лендинг, под формой курса | сценарий курса |
| `prk_web` / `crs_web` | страница «Спасибо» после формы на сайте | найти заявку с сайта по `telegram_username`, привязать чат, подтвердить; если не нашлась — обычный сценарий |
| `wait` | лендинг после старта курса | лист ожидания следующего потока |
| любая другая (например, `tgads_opex_w2`) | реклама прямо в бота | спросить, практикум или курс; метку сохранить |
| без метки | прямой вход | то же |

## Сценарии

**Практикум.** Имя → контакт (Telegram известен, спросить только при желании
email) → роль (консультант / Lean-OpEx в компании / руководитель
трансформации или PMO / другое) → согласие на обработку персональных данных
со ссылкой https://alexshein.com/privacy → подтверждение. Напоминания:
за день и за час до начала, со ссылкой на трансляцию (ссылку задаёт
владелец командой). После практикума — сообщение со ссылкой на
`@Alex_shein_gift_bot?start=after_prk` за записью и шаблоном, и одно
предложение курса со сроком Early Bird.

**Курс.** Имя → роль → тариф (Early Bird показывать только до 2 ноября
включительно; Pro — пока заняты меньше 3 мест) → задача для практики
(можно пропустить) → нужен ли счёт на компанию → согласие → «Заявка
принята, Александр ответит в течение рабочего дня».

**Подтверждение и оплата.** Владелец получает заявку с кнопками
«Подтвердить» / «Отклонить» / «Написать». После подтверждения человеку
приходит оплата через ЮKassa: встроенные платежи Telegram с ЮKassa как
провайдером или ссылка на платёж ЮKassa — выбрать при реализации.
После успешной оплаты — приглашение в закрытый чат курса и сообщение
о том, что будет до старта.

**Лист ожидания.** Имя → роль → «Напишу, когда откроется следующий поток».

## Заявки с сайта

Сервис форм сайта (`alexshein.com/api/register`) шлёт каждую заявку
`POST`-запросом JSON на адрес бота с заголовком `X-Webhook-Secret`.
Формат описан в [FORMS.md](FORMS.md), раздел «Формат заявки». Бот должен:
- принимать такие запросы и проверять секрет;
- хранить их вместе с заявками из самого бота, в одной базе, поле
  `source`: `site` или `bot`;
- при `/start prk_web|crs_web` искать заявку по `telegram_username`
  (без `@`, в нижнем регистре).

Уведомления владельцу о заявках с сайта сервис форм шлёт сам. Бот их
не дублирует, а только привязывает чат.

## Владельцу

- Уведомление о каждой новой заявке из бота: тип, имя, контакт, роль,
  тариф, задача, метка `start`.
- Команды: `/stats` (число записей на практикум, заявок и оплат на курс
  по тарифам), `/export` (CSV всех заявок), `/link <url>` (ссылка
  на трансляцию практикума), `/broadcast_practicum <текст>`.

## Ограничения

- Секреты (токен, ключи ЮKassa, секрет вебхука) — только в переменных
  окружения.
- Хранить минимум персональных данных: имя, контакт, роль, ответы.
- Деплой: Docker + Coolify на том же сервере, что и сайт, с томом для базы.
