# Где и как разместить страницу `/ai-native`

Версия 3 от 08.10.2026. Факты и решения записаны в [README.md](README.md),
текст страницы лежит в [LANDING-COPY.md](LANDING-COPY.md).

## Решение

**Страница на этом сайте: `alexshein.com/ai-native`, только на русском,
устроена так же, как `/hobby`.** Текст хранится в `src/data/ru/course.json`
и правится владельцем в админке. Claude Design даёт макет, а на сайт его
переносят компонентами Astro на токенах дизайн-системы.

Почему не поддомен и не публикация прямо из Claude Design:

1. **Цены, даты и режим страницы меняются посреди кампании.** Early Bird
   закрывается 2 ноября, 31 октября главный призыв переключается
   с практикума на курс, места на Pro заканчиваются. В админке это минута,
   через разработчика — день.
2. **Метрика уже стоит.** Счётчик 111594931 работает с `trackLinks: true`,
   и переходы в ботов считаются без нового кода. Исключение для внешнего
   скрипта в `AGENTS.md` выдано только этому сайту.
3. **Воронка уже идёт сюда.** Блог ведёт на этот сайт, а `/hobby`
   показывает собственные AI-проекты автора.
4. **Требования сайта и брифа совпадают.** На странице нет скриптов,
   и бриф запрещает таймеры и фиктивный дефицит.

Поддомен имеет смысл, только если курс станет отдельным брендом или
понадобится оплата прямо на странице.

## Как подружить Claude Design с сайтом

1. Дайте Claude Design дизайн-систему сайта: `src/styles/tokens.css`
   и `docs/DESIGN-SYSTEM.md` (или весь репозиторий).
2. Дайте текст из [LANDING-COPY.md](LANDING-COPY.md): разделы 1–3 и 5,
   вместе с ограничениями для макета.
3. Попросите десктоп и телефон, обе формы, страницы «Спасибо», аккордеоны
   на `<details>`, без скриптов.
4. Готовый макет считается эталоном, а не исходным кодом. Компоненты `Hero`,
   `SectionHead`, `Accordion` и `Contacts` на сайте уже есть.

## Режим страницы

Одно поле в данных `phase`, владелец меняет его в админке:

| `phase` | Когда | Главная кнопка | Финальный призыв |
|---|---|---|---|
| `practicum` | до 31 октября | Записаться на бесплатный практикум → `#practicum` | про практикум |
| `course` | 31 октября — 6 ноября | Записаться на курс → `#enroll` | про курс |
| `waitlist` | с 7 ноября | Узнать о следующем потоке → бот | про следующий поток |

В режиме `waitlist` блок практикума и форма курса скрываются, программа
и описание остаются: страница продолжает работать на поиск и следующий поток.

Отдельно у каждого тарифа есть поле `closed`. С 3 ноября владелец
ставит его на Early Bird: карточка получает пометку «Набор по этой цене
закрыт», а в форме этот тариф пропадает.

### Логика бота

Бота делают в отдельной сессии Claude Code. Бриф для неё, готовый
к вставке: [BOT-BRIEF.md](BOT-BRIEF.md).

## Формы на сайте

Обе формы — обычный HTML `<form method="post">` на `/api/register`, без
скриптов. Обработчик живёт в этом репозитории отдельным маленьким сервисом:
[FORMS.md](FORMS.md). Там описано, где он лежит, как деплоится, что проверяет,
формат заявки (общий с ботом) и почему запрос остаётся на `alexshein.com`.

Политику персональных данных пишет владелец, формы ссылаются на `/privacy`.

## Аналитика

- **Цели в Метрике** настраиваются в интерфейсе Метрики, код сайта для
  этого не нужен:
  - открыта страница `/ai-native/spasibo-praktikum` — запись на практикум;
  - открыта страница `/ai-native/spasibo-kurs` — заявка на курс;
  - переход по ссылке, содержащей `t.me/AI_native_reg_bot`, — запись через бота;
  - переход по ссылке, содержащей `t.me/Alex_shein_gift_bot`, — забрал подарок.
- **UTM** из рекламы Метрика видит сама, а обработчик форм получает их
  из адреса страницы (см. выше).
- Страницы «Спасибо» закрываются от индексации (`noindex`), иначе цель
  будут засчитывать случайные заходы из поиска.

## Что поменяется в репозитории, когда дойдёт до вёрстки

По схеме из [WORKFLOW.md](../WORKFLOW.md), без пересечения зон:

| Зона | Файлы | Что сделать |
|---|---|---|
| Договор о данных (оркестратор) | `docs/DATA-SCHEMA.md` | поля `course.json`, включая `phase`, `closed` у тарифов, ссылки на ботов и метки |
| Каркас | `src/lib/routes.ts`, `src/pages/sitemap.xml.ts`, `nginx.conf` | `COURSE_PATH = '/ai-native'`, одноязычная страница по образцу `hobby`, адрес в карте сайта (без страниц «Спасибо»), правило `/api/` |
| Вёрстка | `src/pages/ai-native.astro`, `src/pages/ai-native/spasibo-*.astro`, компоненты, `src/styles/site.css` | секции, две формы, страницы «Спасибо»; списки через `?.`, текста в `.astro` нет |
| Контент | `src/data/ru/course.json`, `src/data/ru/meta.json` | текст из LANDING-COPY.md |
| CMS | `public/admin/config.yml` | раздел «Курс AI-native» с русскими подписями, в одном коммите с JSON |
| Картинки | `public/assets/course/` | визуалы и `og:image` |
| Правила | `AGENTS.md` | новая страница в таблице страниц, решение про `/api/` |
| Вне репозитория | сервис бота регистрации | обработчик `/api/register`, база, уведомления |

Ссылки на страницу с сайта: пункт в подвале и плашка на `/hobby` рядом
с AI-проектами. Главное меню сайта посвящено консалтингу, курс туда
лучше не добавлять.

Готово, когда проходят `npm run build`, `npm run check`, `npm run check:cms`
и `npm run check:content`.
